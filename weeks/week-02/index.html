同样三个数，可以是两种东西

必须掌握 · 40 分钟

导航中，“车辆所在位置”和“车辆朝向”都可以写成三个数。但把整张地图往东移动 10 米时，车辆位置要变，朝向不应该凭空改变。位置依赖原点，方向不依赖原点。

点 P：在哪里

相对某个原点的定位。P − Q 给出从 Q 指向 P 的位移向量；P + d 是移动后的新点。两个点直接相加通常没有独立于原点的几何意义。

向量 d：怎么移动

有方向和长度。平移它的画法，不改变这个向量。速度也用向量表达，但有额外的单位；“向量”不自动意味着长度为 1。

坐标系不仅有原点，还有三条基向量

模型局部轴告诉你它自己的“右、上、前”；世界轴提供场景的共同参考。下方红/绿/蓝分别代表 X/Y/Z，标签区分世界与局部。黄色十字是局部角点 P = (0.65, 0.65, 0.65) 的参考世界位置，黄线表示局部 d = (1, 0, 0) 变换后的向量。

模型的刚体变换

只改变黄色方向线；立方体使用下方编辑器的代码。坐标轴和十字始终使用参考变换。

沿着数值追踪一次变换

数值面板由 CPU 按课程约定计算，是用于对照的参考结果；不反推任意 GLSL 的执行结果。轴标签与十字作为诊断叠加层，不参与自定义代码，也不表示表面的真实遮挡。

p_world = o + x e_x + y e_y + z e_z
d_world = d_x e_x + d_y e_y + d_z e_z

o 是局部原点在世界中的位置；e_x、e_y、e_z 是局部三条基向量在世界中的表示；x、y、z 是点的局部分量，d_x、d_y、d_z 是方向的局部分量。转换点要加原点，转换方向不用加。

手算一个不是零旋转的例子

采用右手系、列向量。绕 +Y 轴转 +90° 后，局部 +X 指向世界 −Z。若 o = (2, 0, −1)，局部 P = (1, 2, 0)，则 P_world = (2, 2, −2)；同样分量的方向 d = (1, 2, 0) 则变成 (0, 2, −1)，不再加 o。

vec3 pWorld = (uModel * vec4(pLocal, 1.0)).xyz;
vec3 dWorld = (uModel * vec4(dLocal, 0.0)).xyz;

这里 w=1 与 w=0 是仿射变换对点、方向的编码约定，不是给三维坐标随便补一个数。投影后 w 的作用在第 4 周展开。

提高一档：怎样从世界坐标找回局部分量？

本周局部基底是正交单位基，没有缩放或错切。先把点减去原点 o，再分别与 e_x、e_y、e_z 点积，即 x_local = (p_world − o) · e_x，其他两项同理。方向则不用减原点。这是刚体旋转的逆变换；若基底不再正交单位，不能继续直接套用。

联系重建：外参经常给出 world→camera，而相机位姿可能给出 camera→world。先写明映射方向与轴约定，再决定是否求逆；不要看到一个 R、t 就直接塞入渲染器。

点积，不只是“夹角公式”

必须掌握 + 推导 · 35 分钟

车已经沿道路走了多远？光线是否朝向表面？这些都在问“一个方向上，另一个向量有多大成分”。先看向量 a 在 b 所在直线上的影子，再写公式。

先改长度，再改方向

残差 · b 应接近 0；例如 10⁻¹⁶ 量级的偏差来自浮点舍入，不等于几何上不垂直。

a · b = a_x b_x + a_y b_y + a_z b_z
= ‖a‖ ‖b‖ cos θ

a、b 是同一坐标系中、采用欧氏度量的向量；‖a‖ 是长度，θ 是夹角。点积输出一个标量。将两个非零向量都归一化后，点积就等于 cos θ；一般不能把原始点积直接当作余弦。长度为零时，方向与夹角没有定义，不能强行归一化。

从“影子”推导投影向量

设投影是 αb。残差 a − αb 与 b 垂直，因此 (a − αb) · b = 0，得到 α = (a · b)/(b · b)。于是：

proj_b(a) = [(a · b)/(b · b)] b　(b ≠ 0)

α 是乘在 b 上的系数；投影向量与 b 共线，但可以反向。有符号投影长度是 (a · b)/‖b‖，和 α 不是同一个量。只有 b 为单位向量时，才能写成 (a · b)b。

需要你主动验证的不变量

把 b 乘以任意非零标量，a 在同一条直线上的投影向量不变；b 反向时，有符号投影长度会反号。试着手改 b 的两个分量，核对投影、点积与夹角分别发生了什么。

叉积：从两条边，得到一个垂直方向

必须掌握 + 数值边界 · 35 分钟

重建出一个三角形后，要怎样求表面朝向？先取两条有顺序的边向量 u = B − A、v = C − A。叉积得到与二者垂直的向量；换顺序，法线就翻面。

边向量与法线

u × v = (u_y v_z − u_z v_y,
u_z v_x − u_x v_z, u_x v_y − u_y v_x)

三个分量分别给出叉积向量的 X、Y、Z 分量；方向遵循右手规则。长度 ‖u × v‖ = ‖u‖‖v‖ sin θ，等于两边张成的平行四边形面积；三角形面积是它的一半。单位法线 n = (u × v)/‖u × v‖，前提是叉积非零。

加难点：近平行时，别只检查“是不是精确等于零”

两边几乎平行时，小量扰动就可能明显改变法线。除去边长影响，可看 s = ‖u × v‖/(‖u‖‖v‖) = |sin θ|。它很小时，几何形状接近退化。本实验把 s < 0.01 作为教学提醒，不是通用工程阈值；任意一条边为零时，s 本身也没有定义。

延伸：重建网格与坐标系手性的陷阱

网格顶点绕序、法线朝向与背面剔除设置要一致。把 Z 轴取反属于反射，不是普通旋转；它会改变手性，叉积的符号也要随约定检查。不要只看到画面翻面就把所有法线乘 −1，先核对外参、轴约定和三角形绕序。
