# 第 2 周：向量与坐标系（进阶）

零运行依赖，入口 `index.html`；完整学习建议 7–9 小时，可分次进行。沿用第 1 周的代码编辑与图解偏好，提高推导、反例和诊断要求。

## 启动

统一从 `weeks/` 启动整个课程，一次服务所有周次：

```bash
cd /home/bhw/repos/graphics-learning/weeks
python3 serve.py --port 8003 --bind 127.0.0.1
```

课程首页：**http://127.0.0.1:8003/**。本周入口：**http://127.0.0.1:8003/week-02/**。页面顶部可返回首页或切换已制作周次。按 Ctrl+C 停止；端口占用时换端口并同步修改浏览器地址。

无需安装 npm 或 Python 包。请保留完整 `weeks/` 目录，以包含统一导航资源；也可直接打开 `weeks/index.html`，但浏览器对 file:// 的持久化行为存在差异，长期学习推荐固定 HTTP 地址。课程和实验可离线使用，外部参考链接需要联网。

## 学习顺序与提高的难度

1. 从位置/方向的区别出发，看真实 WebGL 世界轴、局部轴和参考点，改变平移/旋转，对比 w=0 与 w=1。
2. 读基底展开和逆变换的前提，手算非零旋转，联系重建外参的 world→camera / camera→world 映射方向。
3. 在点积图中拖动箭头或输入分量；推导投影公式，对比点积、余弦、有符号投影长度和投影向量。
4. 观察三维叉积、交换顺序、近平行和零边；用非零平行向量构造失败案例，再加入微小扰动。
5. 在 GLSL 工作台直接编辑核心函数体，注入“位置 w=0”“局部法线混用世界光源”两类故障并修复。
6. 完成四项数值题：点的世界坐标、方向的世界分量、三维向量投影、刚体逆变换。数值容差 1e-3。
7. 先预测，运行四姿态图像检验，写修复理由与进一步反例，保存实验。完成八道答后解析题并导出学习记录。

## 图像与数学约定

- 右手系、列向量；绕 +Y 正转 90° 时 +X 变为 −Z。世界 +Y 向上。
- 模型只平移、绕 Y 旋转，不缩放/错切。方向不受平移；法线用旋转部分转换。
- 数值追踪基于 `math.js` 的参考计算；坐标轴和黄色角点独立于学生代码。它们不是从任意着色器读回的结果。
- 轴线是忽略遮挡的诊断叠加层，所有轴都可见不表示它们在表面前方。
- 世界光源为固定方向光，只有简化漫反射和常量底光，没有距离衰减、PBR、纹理、投射阴影或完整颜色管理。
- 点积图在 z=0 平面；叉积图对真正的三维向量作正交投影，自动缩放绘图区。绘图缩放与观察角度不改变输入向量数值。
- 零向量归一化/夹角与零投影轴返回未定义；零面积三角形不伪造单位法线。近平行提醒以 |sin θ|<0.01 为教学阈值。
- 投影计算用等价的单位轴形式避免不必要的平方幅值误差；页面推导保留一般非单位公式。非零微小数以科学计数法显示，避免舍入成零造成误解。

## 核心代码与多姿态检验

编辑器支持顶点/片段函数体、Ctrl/⌘+Enter 运行、当前完整 GLSL 下载和编译日志。语法失败保留旧程序；草稿与成功程序分别持久化。参考轴、地面及点标记不受学生顶点代码影响。

故障 A 只把模型变换输入的位置误作方向，随后仍把所得世界分量按点投影。故障 B 保留局部法线，却与世界光源点积。两类故障都能编译，但行为不正确。

“四组姿态”在同一浏览器中临时运行参考程序与学生当前程序，逐图比较，然后恢复原来的代码、参数和画面。它针对“恢复课程参考几何与默认光照”这一指定目标，不是任意创作的正确性评判，也不是完整证明。三角形、旋转类型、材质和光照设置都有限；非均匀缩放等问题留待后续。

## 记录与隐私

第 2 周使用独立 localStorage 键 `graphics-learning-week-02-v1`，不覆盖第 1 周。保存预测、解释、数值答案、代码草稿/成功程序、已提交的检验案例、测验与复盘。向量输入可随当前记录导出，但不自动在刷新后恢复；故障场景参数也在刷新后回到默认值。

Markdown 导出包含实验代码、姿态/结果与解释；PNG 单独下载。普通网页不自动写回项目目录，代码草稿也不会改写 renderer.js。不向外上传记录；建议自行保存导出文件。

## 文件与检查

- `math.js`：可供浏览器/Node 使用的纯向量数学。
- `renderer.js`：真实 WebGL 场景、独立参考轴及可替换着色器。
- `diagrams.js`：点积/投影与叉积/法线的计算和 Canvas 图解。
- `app.js`：课程交互、代码工作台、挑战、测验和记录。
- `checks/math-check.cjs`：已知数值、退化及 80 组几何不变量检查。
- `checks/browser-check.cjs`：浏览器行为与响应式检查。
- `checks/验证说明.md`：实际验证结果与限制。
