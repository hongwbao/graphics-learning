## 自主阅读

### 为什么直接照明还不够？

红色物体附近的白地面可能染上一点红，物体背光面也可能收到环境和其他表面反射的光。这些现象来自光在表面之间传播；只算 n·L 的单次照明无法表达完整路径。

本实验显式计算一个方向光的可见性作为直接项，再从漫反射表面随机发射新射线，逐次乘上表面反射率。关闭间接散射只保留这个方向光项与相机直接看到的环境，不等于把所有光都关掉。

### 把许多方向的贡献写成积分

L_o(p,ω_o)=L_e(p,ω_o)+∫ f_r(p,ω_i,ω_o)L_i(p,ω_i)|n·ω_i| dω_i

L_o 是离开表面的辐亮度，L_e 是表面自发光，L_i 是入射辐亮度；f_r 是 BRDF，ω_i/ω_o 是入射与出射方向，n 是单位法线，积分在可见入射半球上进行。积分中的量不能只挑一个“漂亮方向”代替。

本页使用 Lambert 漫反射 f_r=ρ/π，其中 ρ 为三个颜色通道的反射率；没有金属或高光 BRDF。方向光直接项用单独的阴影射线评估。实现中的 1.4 是把教学光强与 1/π 合并后的照明系数，不宣称它是经过物理标定的入射辐亮度。

### 随机估计为什么还要除以概率密度？

I ≈ (1/N) Σ [g(ω_k)/p(ω_k)]

N 是样本数，ω_k 是按概率密度 p 产生的方向；g 包含需要积分的 BRDF、入射光和余弦。采到某方向的频率与它的积分权重不同，必须用 PDF 补偿。

本实验在局部半球作余弦加权采样，p(ω)=cosθ/π，与 Lambert 的 ρ/π 和积分的 cosθ 配合后，路径吞吐量只需再乘 ρ。若此时又乘一次 cosθ，就改变了估计量，会让画面产生系统性变暗，而不是仅改变噪声。

### 噪声、偏差和运行时间是三件事

理想独立同分布、有限方差条件下，均值估计的标准误差约按 1/√N 缩小，所以标准差减半通常要约4倍样本。不是说一张图中每个像素的误差都精确减半。

增加样本降低随机波动；增加最大反弹次数减少本例截断路径造成的一类偏差。二者不能互相替代。固定曝光、场景、分辨率与反弹上限，换几个种子观察，再谈“更少噪声”。本页保留原始低分辨率结果，只做显示编码和色调映射，不做降噪。

## 交互实验

真正的漫反射随机路径实验

每个像素发射带抖动的相机射线，命中后以余弦分布散射；以固定种子复现实验。请先比较1与16样本，再比较直接项和间接散射。

### 修改核心计算

```js
const scene=[
 {id:'红球',p:[-.55,-.05,-2.4],r:.65,c:[.72,.18,.08]},
 {id:'蓝球',p:[.85,-.15,-3.0],r:.55,c:[.1,.32,.72]},
 {id:'地面',p:[0,-100.7,-3],r:100,c:[.72,.72,.72]},
 {id:'发光球',p:[0,2.2,-2.7],r:.5,c:[0,0,0],e:[6,5.5,4.5]}
];
// 余弦采样必须与 Lambert 权重配对；可在脚手架中核查 PDF 抵消。
function sample(n,rng){ return cosineDirection(n,rng); }
return renderPath({scene,sample,samples:Number(input.samples),depth:Number(input.depth),
 seed:Number(input.seed),indirect:input.indirect==='on',exposure:Number(input.exposure)});
```

scene 的 c 是线性漫反射率，e 是自发光；sample() 真正决定二次射线方向。先把红球反射率减半，预测周围地面颜色的变化。若要换成均匀半球采样，必须同时在脚手架 trace() 中改吞吐量为 f*cos/pdf，不能只替换随机方向。exposure 只作用于平均后的显示，不改变线性估计均值。

只读脚手架在页面详情与 lesson.js 的 lab.prelude 中可查看；下载代码包括脚手架。修改在 Worker 中执行，错误或超时保留上次图像；不会自动改写磁盘文件。

## 常见误区

- 路径追踪不是“干净图加噪声”或模糊滤镜。
- 固定种子保证同一参数可复现，不代表单个种子的结果等于真值。
- 增加反弹和增加样本不是同一种操作。
- 更亮不一定更准确；显示曝光、错误权重和真实能量变化必须分开。
