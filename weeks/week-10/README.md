## 自主学习讲解

### 先分清照明和材质

如果灯的亮度变两倍、表面看起来更亮，这不是材质本身改变。BRDF f_r 描述从入射方向到出射方向的局部响应，它不是最终颜色，也不包含其他物体是否挡住灯。这里使用不透明、各向同性微表面模型，先固定光源强度，再比较材质。

L_o(v) = f_r(l,v) L_i(l) max(n·l,0)

这是单个方向光的简化直接光形式；n 是法线，l 指向光源，v 指向观察者，L_i 是光源辐亮度。完整渲染方程还要对入射半球积分，并考虑可见性与间接光。

### 微表面：粗糙度控制分布，不是简单减少亮度

宏观平面可以由不同朝向的小面元组成。粗糙度提高，满足镜面反射条件的微面元方向更分散，反射高光往往变宽、峰值降低。仅比较最高亮度不能判断反射能量是否合理。

f_spec = D(h) G(l,v) F(v·h) / [4(n·l)(n·v)]

h=normalize(l+v) 是半程方向；D 表示微表面法线分布，G 近似微表面遮蔽/阴影，F 是 Fresnel 反射比例。实验采用 GGX 的 D 和 Schlick 近似，不要求本周独立推导所有微积分，但必须知道三项分别负责什么。

### 金属与非金属不只是亮一点

常见金属度工作流把 metal=0 近似为非金属：正入射 F0 常取约 0.04，漫反射带基础色。metal=1 近似为金属：本模型关闭漫反射，F0 使用基础色，反射因此可以着色。中间值用于混合/过渡，不自动代表一种真实均匀材料。

F = F0 + (1−F0)(1−v·h)^5
k_d = (1−F)(1−metal)

F 随角度变化，而不是固定一盏“高光灯”。k_d 把一部分能量从漫反射支路中扣除，避免两个支路都无条件拿满入射光。该简化微表面实现不意味着每种参数/所有角度下都已完成严格能量补偿。

### 模型参数只有在约定相同时才能比较

实验将 artist roughness 映射为 α=roughness²，再对 α 设小下限以避免数值尖峰。不同渲染器未必使用完全相同映射。要复现外观，必须同时记录光照、法线、粗糙度约定、基础色是否线性、曝光及输出色调映射。

图像计算在线性 RGB 中进行，显示前用 Reinhard 压缩 c/(1+c)，再作分段 sRGB 编码。显示图像的最高像素值因此不直接等于 BRDF 峰值。重建中“几何解释得通”与“材质参数可辨识”也不是一回事。

## 交互实验

材质球与 GGX 分布：定性与计算对照

真实求值的 CPU 材质球：视角改变会重新选择可见半球法线；光源保持世界方向。右侧画出 GGX D 的对数曲线，辅助分清分布峰值与最终图像。

可调输入：

- 粗糙度 r（roughness）：默认 0.35，范围 0.05–1
- 金属度（metal）：默认 0，范围 0–1
- 观察者绕球 Y 方位（view）：默认 0，范围 -70–70
- 光源世界方位（light）：默认 35，范围 -80–80
- 线性基础色（base）：默认 copper；copper=暖铜色，blue=冷蓝色

### 核心代码

input.samples 提供同一世界空间内的非负 n·l、n·v、n·h、v·h。先改 alpha 的映射或 diffuse 的 (1−metal)，预测哪些材质/角度会暴露差异，再检查是否不当地增加能量。3.0 是固定方向光强度，不是材质参数。

```js
const alpha = Math.max(0.02, input.roughness**2);
const k = (input.roughness+1)**2/8;
const F0 = input.base.map(c=>0.04*(1-input.metal)+c*input.metal);
const colors = input.samples.map(s=> {
  const F = F0.map(f=>f+(1-f)*(1-s.vh)**5);
  const D = ggx(s.nh,alpha);
  const G = smithPart(s.nl,k)*smithPart(s.nv,k);
  return input.base.map((base,j)=> {
    const spec = D*G*F[j]/Math.max(4*s.nl*s.nv,1e-6);
    const diffuse = (1-F[j])*(1-input.metal)*base/Math.PI;
    return (diffuse+spec)*s.nl*3.0;
  });
});
return {colors,F0,alpha};
```

### 只读脚手架

框架先执行下列 helper，再执行核心代码；页面可展开查看，下载包含两部分。

```js
function ggx(nh, a) {
  const a2=a*a;
  return a2/(Math.PI*Math.pow(nh*nh*(a2-1)+1,2));
}
function smithPart(n,k){return n/(n*(1-k)+k);}
```

### 如何判断结果

把光照、法线、BRDF 和显示处理分开；比较峰值与反射能量前先说明测量对象。

### 简化与边界

CPU 直接方向光材质球，GGX + Schlick 近似；无 IBL、多次散射补偿、真实导体复折射率、阴影或路径积分。示例不是材质测量仪，也不保证所有极端参数严格守恒。

## 预测、实验、解释

### 材质、光照、显示各改一次

固定其他变量，依次改变 roughness、metal、view。预测高光宽度、基础色支路、掠射反射应怎样变。记录一个仅靠峰值亮度会误判的例子。

提示：显示图像经过色调映射；不要直接将最亮像素当作线性反射峰值。

### 故意破坏能量分配

先写预测，再把漫反射里的 (1−F) 或 (1−metal) 去掉。解释为什么仅看一个正面视角可能看不出错误，再选择更有区分力的材质与角度。

提示：金属度为 1 时是否仍出现带基础色的漫反射？掠射角时两条支路是否同时接近全量？

## 常见误区

- PBR 是一组有物理约束的近似，不是“调上去就真实”的开关。
- 高光更亮不等于总能量更多，尤其不能跨不同曝光比较。
- 金属度的中间值不自动对应一种真实均匀金属材料。
