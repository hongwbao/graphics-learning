# 第 1 周：从场景到屏幕

入口是 `index.html`。采用原生 HTML、CSS、JavaScript 和 WebGL 1，无 npm、构建步骤、CDN、远程字体、账号或后端。课程与交互可离线使用；外部参考链接需要联网。

## 启动

```bash
cd /home/bhw/repos/graphics-learning/weeks/week-01
python3 -m http.server 8001 --bind 127.0.0.1
```

浏览器打开 **http://127.0.0.1:8001/**。终端按 `Ctrl+C` 停止。使用 Python 标准库是为了提供可靠的本地静态 HTTP 服务，无需安装 Python 包。端口被占用时换为 8002 并同步修改浏览器地址；不同端口的浏览器学习记录互不共享。

也可双击 `index.html` 直接阅读和使用实验；浏览器对 `file://` 的持久化行为存在差异，长期学习推荐固定 HTTP 地址。

## 学习顺序

1. 看学习地图，读“场景里有什么”，回答图像由哪些因素共同决定。
2. 在三维观察室自由探索模型、相机、光源、着色方式和遮挡。每次只改一项。
3. 点击六个管线步骤，读输入、输出与对应代码。理解 M、V、P 的职责即可，不要求第一周推矩阵。
4. 完成 A/B/C 三轮任务：先写预测，执行并看前后对照，再写自己的解释，最后查看参考。
5. 亲手改 `renderer.js` 的 `STUDENT_TODO_X_OFFSET`。默认 0，尝试 0.6 后刷新；滑块值不变，代码偏移量会显示在场景读数中。
6. 完成六道测验和一次 60 秒口头解释，写复盘并导出 `.md`。

建议核心课程约 90 分钟。一周另安排反复实验、修改、查资料和复盘，总计约 6–8 小时；不要求连续学完。不会的数学留到对应周次。

## 实验包含什么

- 真正运行在 GPU 管线中的顶点和片段着色器；两个立方体、地面、相机、方向光。
- 模型横移/旋转、相机横移/距离、光线来向、基础色。
- 简化光照、固定色、法线编码、三角形线框四种显示。
- 开关深度、交换立方体绘制顺序；截图导出 PNG。
- A/B/C 每轮重置到相同基线。颜色任务使用固定色模式，排除光照干扰。

世界采用右手坐标，+X 向右、+Y 向上，相机在 +Z 一侧，保持固定俯视朝向。矩阵使用列向量、列主序，右侧先应用。深度开关只控制两个立方体；地面与网格先绘制并始终使用深度。

## 数学、简化和边界

核心是 `p_clip = P V M p_local` 与相机横移的 `x_view = x_world - camera_x`。页面说明所有符号、坐标约定以及简化光照公式的含义。

- 无外部模型、纹理、PBR、投射阴影或完整颜色管理；只有方向光加常量底光。
- 不完整推导矩阵、透视除法、光栅化覆盖、属性插值或深度精度，分别留到后续周次。
- 教学流程不是 GPU 指令时序；深度测试可提前进行。一个候选片段也不等于最终像素。
- 法线变换只适用于本例旋转/平移/统一缩放；非均匀缩放需另行处理。
- WebGL 1 与桌面 OpenGL 的 API、着色器版本有差异，课程侧重共同的管线概念。

## 学习记录

预测草稿、已提交实验的完整前后参数、解释、测验答案和复盘自动保存于当前浏览器的 localStorage。保存失败会提示改用导出，其他功能仍可用。

导出按钮生成中文 Markdown，包含任务预测、参数、代码偏移、解释、测验与复盘，供你保存到项目中的 `notes/`。出于空间考虑，前后对照图片仅在当前页面生成，不写入 localStorage；需要图片时用“保存场景 PNG”。普通浏览器网页不会自动写回项目目录。

切换任务保留各自草稿；刷新保留文字记录与测验。更换浏览器、端口、站点地址或清除站点数据会影响记录，请及时导出。不上传任何学习记录。

## 开发验证（可选）

网站本身不需要任何 JavaScript 依赖。只有重跑自动浏览器检查才需要 Playwright 和 Chrome/Chromium。

已存在 Playwright 时，在服务器启动后另开终端运行：

```bash
cd /home/bhw/repos/graphics-learning/weeks/week-01
PLAYWRIGHT_PATH=/已有的/node_modules/playwright \
CHROME_PATH=/usr/bin/google-chrome \
node checks/browser-check.cjs
```

也可以在临时目录 `npm install --prefix /tmp/graphics-week01-check playwright`，将 `PLAYWRIGHT_PATH` 指向其安装路径；这只为自动化测试提供浏览器控制，不属于课程依赖。检查使用新建的独立浏览器上下文，不会覆盖你日常浏览器中的学习记录。测试会将截图和示例记录写入 `checks/`。`COURSE_URL` 可覆盖默认地址。
