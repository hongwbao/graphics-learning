## 自主阅读

### 一个像素为什么对应一条射线？

把相机当作针孔，像素中心位于它前方的虚拟成像平面。连接针孔与像素，得到射线方向。方向不是像素颜色；必须继续找它碰到的场景表面。本周相机朝世界 −Z，+Y 向上，图像从上到下遍历时 y 要翻转。

r(t) = o + t d，t ≥ 0

o 是射线起点，d 是非零方向，t 是沿射线的参数。只有 d 的长度为 1 时，t 才等于从 o 到命中位置的欧氏距离。若忘了归一化，求交仍能成立，但不能继续把 t 无条件当作米或距离。

### 把几何条件变成二次方程

球心 c、半径 R 的球面满足 ‖p−c‖²=R²。将 p=o+td 代入，令 q=o−c，可得：

a t² + 2 h t + k = 0
a=d·d，h=q·d，k=q·q−R²
Δ=h²−ak，t=(-h ± √Δ)/a

Δ<0 表示没有实交点；Δ=0 是相切；Δ>0 常有进入和离开球面的两个交点。不要把本周的半 b 形式 h 与教科书完整 b 形式混用，否则会多出或漏掉一个 2。

### 最近的交点，必须处于有效区间

从球外看，较小正根通常是入口；相机在球内时，小根可能为负，应该尝试另一个根。遍历多个物体时，保留 t_min<t<t_best 的最近命中。只返回“存在交点”的布尔值，不能决定遮挡。

本实验的“远根优先”会优先尝试每个球的较大根；若它不在当前 t_min 到 t_best 的有效区间内，会回退尝试小根。仍然比较不同物体的 t。这是一个可编译、可运行但通常错误的可见性策略，用法线调试图比看最终颜色更容易定位。

### 反射是一条新射线，不是一张固定贴图

在命中点求单位法线 n。入射方向 d 指向表面，理想反射方向为：

d_reflect = d − 2(d·n)n

该式要求 n 为单位法线。沿新方向再次寻找最近命中，镜面中才会出现其他物体。新起点略沿表面法线偏移，避免浮点误差使射线立即击中自己；偏移过大又会漏掉近处细节。

联系 3D 重建：渲染器会把网格或体表示交给求交结构。本周只用解析球以隔离几何问题；球不代表真实重建场景，但“相机射线、最近命中、法线和可见性”的职责可以迁移。

### 修改核心计算

```js
const fov = 50 * Math.PI / 180, aspect = 160/100;
function direction(u,v){ return unit([u*Math.tan(fov/2)*aspect, v*Math.tan(fov/2), -1]); }
function reflector(d,n){ return sub(d, scale(n, 2*dot(d,n))); }
const scene = [
 {id:'主球',p:[0,0,-2.5],r:Number(input.radius),c:[.2,.65,.48],m:.8},
 {id:'参照球',p:[1.05,-.1,-3.2],r:.55,c:[.75,.18,.08],m:.05},
 {id:'地面',p:[0,-100.7,-3],r:100,c:[.65,.68,.63],m:.05}
];
return renderRay({scene,origin:[Number(input.cameraX),.15,0],direction,reflector,
 mode:input.mode,depth:Number(input.depth),farRoot:input.root==='far',probeX:Number(input.probeX),shadow:true});
```

direction() 从 NDC 像素生成世界射线；先切到法线模式，再把方向归一化去掉，隔离命中位置与 t 的关系。背景 sky(d) 假设单位方向，去掉归一化还会改变未命中处的天空着色，不能把这种背景变化误判为几何变化。reflector() 是反射核心，修改前用垂直入射与擦边入射检验方向。scene 中 p、r、c、m 分别是球心、半径、线性基础色、镜面混合权重。完整求交/绘制脚手架可在源码详情查看。

只读脚手架在页面详情与 lesson.js 的 lab.prelude 中可查看；下载代码包括脚手架。修改在 Worker 中执行，错误或超时保留上次图像；不会自动改写磁盘文件。

## 理解检查

1. d 未归一化时，t 一定是欧氏距离吗？
   A. 一定
   B. 不一定，取决于 d 的长度
   C. 只要球半径为1就一定

<details><summary>作答后查看解析</summary>

参考选项：B。位移长度是 |t|‖d‖。方向单位化后，正 t 才直接表示距离。

</details>

2. 相机在球内部，较小根为负时应如何？
   A. 直接判定无交点
   B. 尝试有效区间内另一个根
   C. 取负根绝对值

<details><summary>作答后查看解析</summary>

参考选项：B。负根位于射线起点后方，另一个正根可能是离开球面的命中。

</details>

3. 多个球都命中时，最终可见表面如何确定？
   A. 场景数组最后一个球
   B. 有效正 t 最小的命中
   C. 半径最大的球

<details><summary>作答后查看解析</summary>

参考选项：B。可见性由沿射线的最近有效命中决定，不由提交顺序或大小决定。

</details>

4. r=d−2(d·n)n 的常用形式要求什么？
   A. n 为单位法线
   B. d 必须等于 n
   C. n 的长度任意都可以

<details><summary>作答后查看解析</summary>

参考选项：A。非单位 n 会错误缩放法线分量；可先归一化或使用带 n·n 分母的一般投影形式。

</details>

5. 新射线起点小偏移主要解决什么？
   A. 提高几何精度到无限
   B. 减少浮点误差导致的自相交
   C. 代替最近交点选择

<details><summary>作答后查看解析</summary>

参考选项：B。偏移减少立即再击中同一表面的风险，但过大会漏掉近邻结构。

</details>

## 常见误区

- 追踪射线并不自动意味着物理正确；材质、光源和采样仍决定结果。
- 两个实根不等于两个都在相机前方。
- 镜面反射需要二次可见性查询，不能仅通过把主球调亮实现。
- 法线编码是调试颜色，不是材质的真实反射色。
