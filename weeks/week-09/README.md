# 第 9 周：法线与光照：几何没动，明暗为什么变了？

让法线保持垂直，比“跟着模型乘一下”更重要。

你的重建表面形状看起来对，光照却随着缩放变得不合理。先区分点、方向和法线：法线不是任意方向向量，它必须与变换后的切平面继续垂直。

## 自主学习讲解

### 明暗先是一个方向关系

把一张平板从正对灯转到侧对灯，单位面积接收到的直接照明通常减小。Lambert 漫反射用 max(n·l,0) 表达这个方向权重；n 是单位外法线，l 是从表面指向光源的单位方向，两者必须在同一坐标空间。

L_diffuse ∝ ρ max(n · l, 0)

ρ 是表面漫反射系数。这个公式不表示所有材质都如此，也没有替你求遮挡、距离衰减或间接光。先隔离一项，再扩展模型。

### 法线是与切平面垂直的约束

若表面切向量 t 与法线 n 满足 n·t=0，几何线性变换 A 后，切向量变成 At。我们需要 n′·(At)=0。因此可取 n′=(A⁻¹)ᵀn，再归一化。它不是“为了看起来漂亮”的修正，而是保存垂直关系。

n′ = normalize((A⁻¹)ᵀ n)

本实验 A=diag(s_x,1,s_z)，所以未归一化的新法线是 (n_x/s_x,n_y,n_z/s_z)。若误用 A n，则把两个应缩小的分量反而放大。纯旋转时 A⁻ᵀ=A，所以第 2 周的简写在当时成立。

### 高光还依赖观察方向

漫反射在这个简化模型中不随观察方向变化；镜面高光要额外考虑观察方向 v。Blinn–Phong 常用 h=normalize(l+v) 与 max(n·h,0)^p。p 越大，高光通常越集中；这不是第 10 周粗糙度的物理定义。

本页观察方向固定为朝向屏幕的 +Z，便于只改变法线和光源。你可修改代码中的指数，观察高光分布；不要把它当作真实相机移动的模拟。

### 给重建网格排错：形状、绕序、法线分开看

三角形法线可以由两条边叉积得到；顶点法线还可能由邻面平均，形成不同的光滑外观。法线错误、面绕序错误、坐标系反射都可能让高光翻面，但原因不同。

用法线方向编码为 RGB，先检查方向随模型变化是否合理，再恢复照明。如果只调亮度掩盖错误，后续材质参数会变成补偿项，难以迁移到新视角。

## 交互实验

非均匀缩放下的法线对照

左侧始终采用逆转置参考，右侧由核心代码决定。改变 X/Z 缩放与世界光源来向，看椭球轮廓相同但明暗是否一致。

可调输入：

- X 方向缩放 s_x（sx）：默认 1.5，范围 0.35–1.8
- Z 方向缩放 s_z（sz）：默认 0.5，范围 0.35–2
- 世界光源绕 Y 来向（light）：默认 35，范围 -160–160
- 右侧变换策略（normalMode）：默认 correct；correct=逆转置，wrong=误用模型缩放
- 显示（display）：默认 lit；lit=漫反射 + 简化高光，normal=世界法线编码
- 高光指数 p（shininess）：默认 32，范围 4–128

### 核心代码

关键是 transformed 的两行：非均匀缩放时为什么用除法？unit 只改变长度，不能修复方向已错的 transformed。可替换法线策略或高光表达式，再用左侧参考和几何垂直关系双重核验。

```js
const l = unit(input.lightDirection);
const h = unit(add(l, [0,0,1]));
const colors = input.samples.map(sample => {
  const q = sample.n;
  const transformed = input.normalMode === 'wrong'
    ? [q[0]*input.sx, q[1], q[2]*input.sz]
    : [q[0]/input.sx, q[1], q[2]/input.sz];
  const n = unit(transformed);
  if (input.display === 'normal') return n.map(v=>v*.5+.5);
  const diffuse = Math.max(0, dot(n,l));
  const specular = Math.pow(Math.max(0,dot(n,h)),input.shininess);
  return [0.15+0.25*diffuse+0.5*specular,
          0.18+0.55*diffuse+0.5*specular,
          0.16+0.42*diffuse+0.5*specular];
});
return {colors};
```

### 如何判断结果

法线变换应保存与切向量的垂直关系；归一化不能消除空间或方向错误。

### 简化与边界

CPU 解析椭球表面采样，固定观察方向，无真实 GPU、阴影、距离衰减、法线贴图或物理 BRDF。只比较可逆正缩放，未实现镜像和奇异矩阵。

## 预测、实验、解释

### 先找一个让错误实现通过的测试，再找反例

预测均匀缩放时模型矩阵法线为何可能看似正确。随后设置 s_x=1.6、s_z=0.4 并转动光源，记录差异。给出一组法线与切向量，用点积判断两种变换的正确性。

提示：可取 n=(1,0,1)、t=(1,0,−1)。先变换 t，再检查两个候选法线与它的点积。

### 高光变了，形状一定变了吗？

固定缩放与光源，修改高光指数。解释轮廓、漫反射、高光各应怎样变，说明为什么不能只凭高光位置诊断重建几何。

提示：这是固定视向的局部着色实验；变化可能来自着色模型和法线。

## 理解检查

### 1. 非均匀缩放下，法线为何不能总用 A n？

1. 因为法线不能归一化
2. 它一般不再垂直于 A t
3. 因为矩阵无法处理方向

<details><summary>作答后再看解析</summary>

答案：2。法线的几何约束是与切平面垂直；逆转置保存 n′·At=0。

</details>

### 2. A 为纯旋转时，A⁻ᵀ 与 A 有何关系？

1. 相同
2. 一定相反
3. 无关

<details><summary>作答后再看解析</summary>

答案：1。正交旋转的逆等于转置，所以逆转置回到原旋转。

</details>

### 3. 把错误变换后的法线 normalize 一次，就能修复吗？

1. 能
2. 不能，归一化只处理长度
3. 只要向量非零就能

<details><summary>作答后再看解析</summary>

答案：2。方向已经错了时，单位化不会让它重新垂直于切平面。

</details>

### 4. 本页单位 n 与 l 的点积描述什么？

1. 表面相对光源的方向权重
2. 是否被另一物体遮挡
3. 完整材质反射

<details><summary>作答后再看解析</summary>

答案：1。max(n·l,0) 是直接漫反射的方向项，不求可见性或完整 BRDF。

</details>

### 5. 单位法线 n=(1,0,0) 编码到 n×0.5+0.5 的 RGB 是？

1. (1,0,0)
2. (1,0.5,0.5)
3. (0.5,0.5,0.5)

<details><summary>作答后再看解析</summary>

答案：2。将每个 [-1,1] 分量映到 [0,1]，编码色不是材质色。

</details>

## 常见误区

- 亮度不合理不一定来自光强，也可能来自法线空间混用。
- 逆转置后仍需归一化；但单位化不能代替逆转置。
- 本页 Blinn–Phong 指数不是 PBR 粗糙度的同义参数。
