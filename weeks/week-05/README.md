## 概念与必要数学

### 先问覆盖，再问颜色

一个三角形投到屏幕后，光栅化器需要回答每个采样位置是否被覆盖。为建立直觉，本实验让每个像素只采样中心一次：中心在三角形内便产生候选片段，否则保持背景。像素与三角形有一点重叠，并不保证这个中心采样命中。

候选片段不等于最终像素：遮挡、深度测试、混合等步骤还可能改变结果。本周只研究覆盖与属性插值，下一周再决定哪个表面能留下。

### 用三块有向面积得到权重

P = λ_A A + λ_B B + λ_C C

λ_A + λ_B + λ_C = 1

A、B、C是屏幕中的三个顶点，P为待检查的采样点；λ_A、λ_B、λ_C为重心坐标。每个权重可由对边三角形的有向面积除以总有向面积求得。分母为零表示三个顶点共线，不能继续除。

对一致的顶点方向，内部权重都非负；外部通常至少有一个为负。在顶点A处权重应为(1,0,0)，在边AB上λ_C应为0。这些比“画面看着差不多”更可靠。本实验把数学Y向上转换成Canvas的Y向下时显式翻转。

### 同一组权重，可以插值很多属性

q(P) = λ_A q_A + λ_B q_B + λ_C q_C

q可以是颜色分量、UV坐标或其他顶点属性。将A/B/C分别设为红/绿/蓝，颜色就把权重可视化了：越接近某个顶点，其对应分量越大。三角形内部不需要为每个像素手写一份颜色。

注意本图直接在数值颜色分量上混合，用来查看权重；显示器的颜色编码与线性光意义会在第12周展开，不能把这张权重示意当成物理光照计算。

### 透视下，屏幕权重不一定就是原属性权重

q = [Σ_i (λ_i q_i / w_i)] / [Σ_i (λ_i / w_i)]

w_i是三个顶点的裁剪空间w，λ_i仍由投影后的屏幕位置计算。透视除法改变了参数化速度，所以通常需要先插值q/w与1/w，再相除。若所有w相等，公式退化为普通屏幕线性插值。

实验固定三角形屏幕位置，只改变B顶点的w来隔离插值现象。它模拟一组投影后位置相同、深度关系不同的三维三角形；不要把w滑块误认为在直接移动屏幕顶点。

延伸：共享边为什么不能两边都随便包含？

真实光栅化器使用一致的边界归属规则避免相邻三角形在共享边重复覆盖或漏缝。本图对边界采用含端点的简单判定；它不实现GPU的完整子像素精度、top-left规则或MSAA。

## 交互实验：把重心坐标放到像素格上

左侧是连续三角形与采样格；右侧是实际中心覆盖和属性插值。拖动C的高度直到共线，比较分辨率与透视校正，并追踪一个采样点的三个权重。

可调参数：

- `resolution`：采样网格边长 N，默认 20。
- `cy`：顶点C的Y，默认 0.85。
- `sampleX`：检查位置X（转换为所在像素中心），默认 0.425。
- `sampleY`：检查位置Y，默认 0.425。
- `wB`：B顶点裁剪w，默认 3。
- `mode`：属性插值方式，默认 affine。

预设对照：退化三角形；正常三角形；相同w时两种插值一致；拉大透视差异。

### 亲手修改核心代码

area是二维叉积给出的两倍有向面积，除以total得到λ。可故意去掉total归一化，检查权重和是否仍为1；也可把透视校正分母删掉，解释为何数值被错误缩放。颜色数组代表R/G/B三个基色的权重。

```js
const total=area(A,B,C);
const bary=p=>Math.abs(total)<1e-12?null:
  [area(p,B,C),area(A,p,C),area(A,B,p)].map(x=>x/total);
const shade=weights=>{
  if(input.mode==='affine')return weights;
  const divided=weights.map((x,i)=>x/[1,input.wB,1][i]);
  const sum=divided.reduce((a,b)=>a+b,0);
  return divided.map(x=>x/sum);
};
return rasterize(bary,shade,total);
```

框架把脚手架与上面的核心函数体合并后放进 Worker 执行；返回的数据驱动画布。编辑成功代码后控件沿用新版本，错误/超时保留上次图像。可下载包含脚手架的完整核心实验代码。

### 应该观察到什么

覆盖是采样判定，插值是属性计算；权重和、顶点值与相同w对照是调试的三个抓手。

### 简化与不能推出的结论

CPU中心采样的三角形教学光栅器，省略GPU子像素/边归属规则、MSAA、深度和颜色管理；透视w独立于屏幕几何调节，以隔离插值差异。

## 预测、实验、解释任务

### 推导并手算一个权重

固定A=(0.15,0.15)、B=(0.85,0.15)、C=(0.35,0.85)，先算P=(0.35,0.35)的重心坐标。再找到附近的实际像素中心，说明为什么实验读数不必和手算点完全相同。

需要时再看提示：采样点先被映射到像素中心，P的输入滑块不是任意精度连续采样。

### 让覆盖数量变化，却不改三角形

固定几何，只修改N。先预测覆盖数量与覆盖面积的关系，再比较低/高分辨率；解释为什么像素数不是面积的精确连续值。

需要时再看提示：边缘是离散取样，不能期待任意N都严格乘N²比例。

### 构造透视插值的失败案例

先令wB=1确认两种模式相同，再令wB=6。选取一个内部采样点，手算校正公式并解释哪个权重变小；最后删除代码中的归一化分母来证伪。

需要时再看提示：固定屏幕权重时，B对应项先除以更大的w。

## 常见误区

- 把像素方格相交当作中心采样命中：先声明采样位置。
- 把重心坐标当成固定顶点标签：权重随采样位置而变化。
- 把屏幕插值直接用于所有三维属性：检查是否需要透视校正。
